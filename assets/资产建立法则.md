# 角色资产建立法则

角色资产不是只做一张好看的设定图，而是建立一套可复用的“角色 Bible + 可视参考包 + 用途记录”，用于后续生图、视频生成、分镜审查和一致性 QC。

## 1. 角色 Bible 必须记录

每个主要角色单独建立一份角色说明，至少包含：

- 身份、性别、年龄感、人物关系
- 正脸结构、侧脸轮廓、肤色、五官特征
- 发型、发色、眼镜、胡须、妆容等固定识别点
- 身高、体型、肩宽、头身比、与其他角色的比例关系
- 固定服装、鞋子、饰品、随身道具
- 常用表情、动作习惯、站姿 / 坐姿 / 走路方式
- 剧情状态变化：受伤、感染、疲惫、脏污、换装等
- 禁用项：不能变脸、不能换发型、不能乱换衣服、不能增加无关饰品等

## 2. 必备视觉参考包

主要角色最低要有：

- 正面参考
- 侧面参考
- 背面参考
- 全身比例参考，例如“女孩 A，身高 1.63 米，瘦小体型，肩窄，头身比约 7 头身”
- 脸部近景
- 关键表情参考：平静、紧张、恐惧、愤怒、哭泣等按剧情需要补
- 关键动作参考：奔跑、回头、跌倒、举手、持物、攻击、防御等按剧情需要补
- 固定服装、鞋子、饰品、随身道具参考
- 状态变化参考：干净版、受伤版、感染版、雨淋版、血污版等按剧情需要补

三视图只是最低门槛，不能只靠三视图完成角色资产。

## 3. 非人类角色资产

如果角色是机器人、动物、怪物、异形、生物感染体等，也按“角色 Bible + 可视参考包 + 用途记录”建立，只是识别点从人脸扩展为外形结构和运动特征。

### 机器人

必须记录：

- 机型身份、用途、阵营、尺寸和重量感
- 头部 / 面屏 / 摄像头 / 传感器等识别点
- 躯干、四肢、关节结构、机械连接方式
- 材质：金属、塑料、磨损、锈迹、发光件、涂装
- 固定配件：武器、工具、背包、电缆、编号、标识
- 运动方式：轮式、履带、双足、四足、悬浮、机械臂动作
- 状态变化：完好、破损、断电、感染、过热、战损、发光异常
- 禁用项：不能随意变形、不能多出肢体、不能丢失关键零件、不能改变尺寸比例

### 动物

必须记录：

- 物种、品种、年龄感、体型和比例
- 头部轮廓、眼睛、耳朵、鼻口、毛色 / 皮肤 / 羽毛 / 鳞片特征
- 四肢、尾巴、爪、角、翅膀等固定结构
- 运动方式：奔跑、跳跃、爬行、飞行、游动、扑咬等
- 典型姿态和情绪表现：警觉、攻击、害怕、亲近、受伤
- 状态变化：湿毛、脏污、受伤、感染、变异等
- 禁用项：不能变物种、不能改变毛色 / 斑纹 / 角形 / 尾巴等关键识别点

### 怪物 / 异形 / 感染体

必须记录：

- 来源设定：感染、变异、机械改造、外星生物、实验体等
- 整体轮廓和剪影：高矮、胖瘦、背部、头部、肢体数量
- 核心识别点：眼睛、口器、牙齿、触手、骨刺、鳞甲、发光器官、伤口
- 皮肤 / 外壳材质：湿润、腐烂、硬壳、鳞片、肉质、金属混合等
- 运动方式：拖行、爬墙、抽搐、突袭、缓慢压迫、群体涌动等
- 攻击方式和交互方式：扑咬、抓挠、喷射、寄生、撞击、缠绕
- 状态变化：初期感染、中期变异、完全怪物化、受伤、死亡
- 禁用项：不能每镜随机换形态；除剧情设定外，肢体数量、体型比例、核心特征必须稳定

非人类角色同样需要正面、侧面、背面、全身比例、近景细节、关键动作、状态变化参考；如果有可懂人声、广播声、设备语音等 `Speech`，也要建立音色参考。

## 4. 音色参考

音色参考只收 `Speech`：人物对白、旁白、广播、电话 / 对讲机 / 设备语音等可懂人声。环境声、脚步、机械运转、武器声、动物叫声、怪物嘶吼等不作为音色参考；这些应另归为 Sound / Foley 参考。

如果角色会说话，或机器人 / 设备 / 广播有可懂语音，必须准备或标记音色参考：

- Speech 来源类型：画面内角色 / 旁白 / 广播 / 设备语音 / 对讲机等
- 性别和年龄感，或设备 / 机器人语音风格
- 音高、音色厚薄、明亮度、气息感、机械感或电台质感
- 语速、停顿、重音、尾音
- 情绪强度和说话方式
- 口音、咬字习惯
- 可用的干净音色参考片段及时间码

音色参考必须尽量干净：优先选择单一说话源、无音乐、无强环境声、无重叠对白、无明显混响和噪声的片段。若源片段里音乐、爆炸、脚步、机械声、怪物声或多人声音比较杂，必须先清洗 / 分离 / 降噪，只保留目标 `Speech`，再作为音色参考；清洗后的文件要记录路径、来源视频和时间码，原始混合音频不作为资产保留，处理完成后直接丢掉，除非用户明确要求保留溯源文件。

没有可靠干净的 `Speech` 音色参考时，必须明确标记“待补充 / 待确认”，不能假装已经确认。

## 5. 写实风格与一致性规则

- 默认视觉风格必须是写实、真实感、电影质感，不使用卡通、二次元、Q 版、插画、塑料玩具感、过度磨皮或明显 AI 感风格，除非用户明确要求。
- 角色材质、皮肤、毛发、金属、衣料、伤口、脏污、光影和空间透视都要符合真实物理质感。
- 主体一致性优先级高于单张图好看：宁可画面保守，也不能为了风格化导致换脸、换体型、换结构、换服装或关键特征漂移。
- 所有角色图必须保持同一身份识别点：人物锁脸 / 发型 / 体型 / 服装；机器人锁结构 / 材质 / 配件；动物锁物种 / 斑纹 / 体型；怪物锁剪影 / 肢体数量 / 核心器官。
- 多角色同框时，要建立角色身高、肩宽、头身比或体型尺度的比例关系。
- 同景深下，相对高度、宽度和体型比例偏差原则上不超过 8%，除非有明确透视原因。
- 状态变化可以改变脏污、伤口、破损、发光、感染程度、表情和姿势，但不能改变角色身份识别点。
- 不允许出现水印、平台标识、乱码文字、字幕或无关文字元素。

## 6. 用途记录

每张图都要记录用途，避免后续混用。建议记录：

```text
文件路径：
角色名：
资产类型：正面 / 侧面 / 背面 / 脸部近景 / 表情 / 动作 / 服装 / 道具 / 状态变化 / Speech 音色参考 / Sound-Foley 参考
具体用途：锁脸 / 锁服装 / 锁比例 / 锁动作 / 锁道具 / 锁状态 / 锁 Speech 音色 / 标记非 Speech 声音参考
禁用项：
备注：
```

后续用于 shot 时，也要说明每张参考图的作用，例如：

```text
Image 1: character identity and face lock
Image 2: wardrobe and prop lock
Image 3: action pose reference
```

## 7. 缺失处理

- 缺正面、侧面、背面任一基础角度时，要补生成。
- 补图不得覆盖用户原图。
- 缺干净 `Speech` 音色参考时，只标记“待补充 / 待确认”，不要强行编造。
- 如果只有混合音频，必须先清洗 / 分离 / 降噪出目标 `Speech`；清洗成功后只保留干净 `Speech` 文件和来源时间码，原始混合音频直接丢掉；清洗失败则不能作为已确认音色参考。
- 后续镜头需要什么，就提前补什么：表情、动作、状态变化、服装、道具、比例参考等。
- 不要无目的批量泛生成，也不要等到视频生成时才临时补关键图。

## 8. QC 检查

生成后至少检查两轮：

1. 单图检查：脸、年龄、体型、服装、手脚、动作、道具、比例、光线、文字、水印。
2. 连续性检查：相邻镜头并排看身份、发型、服装、道具状态、角色比例、出入画方向和光线色调是否一致。
3. 音频检查：音色参考只验收干净 `Speech`，不能混入明显音乐、环境声、武器声、机械噪声、怪物叫声或多人重叠；混杂时先清洗，清洗失败则标记待补充。

## 9. gpt-image2 参考程序

文生图：

```bash
python <PROJECT_ROOT>/aifilm_booklet/tools/gpt_image_gateway.py \
  --prompt "写实真实感电影风格，主体一致性优先。角色资产提示词，写清身份、年龄、脸、发型、体型、服装、道具、姿态、光线、真实材质、禁止项，no cartoon, no anime, no illustration, no toy-like, no text, no watermark, no logo" \
  --out <PROJECT_ROOT>/output/images_prepare/角色名_正面.png \
  --size 1536x864 --quality medium
```

参考图编辑：

```bash
python <PROJECT_ROOT>/aifilm_booklet/tools/gpt_image_gateway.py --edit \
  --image <PROJECT_ROOT>/input/roles/角色名/正面.png \
  --prompt "Image 1: character identity. Preserve subject identity, face/structure, age, hairstyle, body type, wardrobe/materials and realistic cinematic style. 生成所需角度 / 表情 / 动作 / 状态变化。No cartoon, no anime, no illustration, no toy-like, no text, no watermark, no logo." \
  --out <PROJECT_ROOT>/output/images_prepare/角色名_补充资产.png \
  --size 1536x864 --quality medium
```
